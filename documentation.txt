1. DATA STRUCTURES USED

1.1 Message Structure

* seq: Sequence number of the message
* ack: Flag to indicate ACK (1) or data (0)
* data[512]: Actual message data

1.2 KTP Socket Structure (KSocket)

* sockfd: UDP socket descriptor
* addr: Source address
* peer: Destination address
* base: First unacknowledged sequence number
* next_seq: Next sequence number to send
* expected_seq: Next expected sequence number at receiver
* window[WINDOW_SIZE]: Sender sliding window buffer
* send_time[WINDOW_SIZE]: Timestamp for timeout tracking
* lock: Mutex for synchronization

---

2. FUNCTIONS IMPLEMENTED

2.1 k_socket()

* Creates UDP socket
* Initializes sliding window variables
* Starts receiver and sender threads

2.2 k_bind()

* Binds socket to a specific port

2.3 k_connect()

* Stores destination IP and port

2.4 k_sendto()

* Sends data packets
* Maintains sliding window
* Stores packet and timestamp

2.5 Receiver Thread

* Receives data and ACK packets
* Simulates packet loss using dropMessage()
* Sends ACKs for correctly received packets

2.6 Sender Thread

* Monitors timeout for unacknowledged packets
* Retransmits packets using Go-Back-N protocol

2.7 dropMessage(float p)

* Simulates unreliable network
* Drops packets with probability p

---

3. THREADS

---

Thread R (Receiver Thread):

* Continuously listens for packets
* Processes incoming data and ACKs
* Simulates packet loss

Thread S (Sender Thread):

* Periodically checks for timeout
* Retransmits packets if ACK not received

---

4. WORKING PRINCIPLE

---

1. Sender reads input file in 512-byte chunks
2. Each chunk is assigned a sequence number
3. Packets are sent using UDP
4. Receiver:

   * Receives packets
   * Simulates packet drop
   * Sends ACK for correct packets
5. If ACK not received within timeout:

   * Sender retransmits all packets in window (Go-Back-N)

* Sequence numbers
